# 栞 SHIORI — 毎日ひとつ、偉人・名著の一言

日付ごとに一言が決まる読書アプリです。開いた日の一言（本文・原文・出典・生没・人物紹介）を表示し、
「書架」から全190句を年代順に眺めたり、心に残った句に「しるし」をつけたりできます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 単体で開ける完成品。ダブルクリックでブラウザに表示できます |
| `app.html` | 画面の本体（デザイン・仕組み）。Artifact 公開用はこちら |
| `quotes.js` | 引用データ（著者147人・190句）。句を増やすときはこのファイルだけ編集 |
| `build.sh` | `app.html` から `index.html` を組み立てる（`app.html` を変えたら実行） |

## 一言の選ばれ方

- その日の日付から機械的に決まるので、同じ日に開けば誰でも同じ句になります。
- 190日ごとに並び順が変わり、一巡するまで同じ句は出ません。
- 「前の日」で過去の句に戻れます（未来は見られません）。

## 句を増やすには

`quotes.js` の `SHIORI_QUOTES` に1行足します。

```js
{a:"夏目漱石", w:"『草枕』", t:"とかくに人の世は*住みにくい*。", x:"（原文があれば）", m:"lamp"},
```

- `a` は `SHIORI_AUTHORS` に登録済みの名前にする（未登録なら著者も1行追加）
- `*語*` で囲んだ部分が辛子色のマーカーになる（1か所だけ）
- `m` は図版の種類: `book` `quill` `lamp` `hourglass` `laurel` `candle` `moon`
- 実在しない引用は入れない。出典 `w` を必ず添える

## iPhone でアプリのように使う

Safari で開き、共有ボタン →「ホーム画面に追加」。以後はホーム画面のアイコンから開けます。
「しるし」と文字サイズの設定は、その端末のブラウザに保存されます。

## デザインの出どころ

指定の参考画像（生成り紙・明朝・青い銅版画・辛子色マーカー・アーチ）に合わせています。
フォントは Shippori Mincho（和文）、Cormorant Garamond（欧文）、Josefin Sans（小さな見出し）。
図版はすべて SVG で描いた線画なので、外部の画像には依存しません。
