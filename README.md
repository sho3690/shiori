# 栞 SHIORI — 毎日ひとつ、偉人・名著の一言

日付ごとに一言が決まる読書アプリです。開いた日の一言（日本語・英語・出典・生没・人物紹介、英語以外の原文があればそれも）を表示し、
「書架」から全374句を年代順に眺めたり、心に残った句に「しるし」をつけたりできます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 単体で開ける完成品。ダブルクリックでブラウザに表示できます |
| `app.html` | 画面の本体（デザイン・仕組み）。Artifact 公開用はこちら |
| `quotes.js` | 引用データ（著者265人・374句）。句を増やすときはこのファイルだけ編集 |
| `build.sh` | `app.html` から `index.html` を組み立てる（`app.html` を変えたら実行） |
| `manifest.webmanifest` / `icons/` | ホーム画面に追加したときの名前とアイコン。`icons/icon.svg` を直して `qlmanage -t -s 1024 -o icons icons/icon.svg` → `sips -z 512 512 …` で PNG を作り直せます |
| `sw.js` | 一度開いた後は電波が無くても開けるようにする仕組み |

## 一言の選ばれ方

- その日の日付から機械的に決まるので、同じ日に開けば誰でも同じ句になります。
- 切り替わるのは毎朝7時です。夜更かしして0時を過ぎても、朝7時までは同じ一言のままです（一日の区切りを「朝」に置いています）。開いたままでも7時に自動で切り替わります。
- 374日ごとに並び順が変わり、一巡するまで同じ句は出ません。
- 2026年9月16日の朝7時から、句を374に増やした新しい並びに入ります（それより前の日は190句だった頃と同じ並びのまま。切り替え直前の90日間に出た句は、新しい並びでは最後のほうに回してあります）。
- 「前の日」で過去の句に戻れます（未来は見られません）。

## 句を増やすには

`quotes.js` の `SHIORI_QUOTES` に1行足します。

```js
{a:"夏目漱石", w:"『草枕』", t:"とかくに人の世は*住みにくい*。", e:"（英語）", x:"（英語以外の原文があれば）", m:"lamp"},
```

- `a` は `SHIORI_AUTHORS` に登録済みの名前にする（未登録なら著者も1行追加）
- `e` は英語。原文が英語なら `x` に入れれば `e` は不要
- `*語*` で囲んだ部分は「古書」の装いで辛子色のマーカーになる（1か所だけ）
- `m` は図版の種類: `book` `quill` `lamp` `hourglass` `laurel` `candle` `moon` `compass` `key` `tree` `telescope` `bird` `bell`（古書の銅版画。海辺・森ではこの種類に応じた風景が句ごとに選ばれます）
- 実在しない引用は入れない。出典 `w` を必ず添える

## iPhone でアプリのように使う

Safari で開き、共有ボタン →「ホーム画面に追加」。以後はホーム画面のアイコンから開けます。
「しるし」と文字サイズの設定は、その端末のブラウザに保存されます。

## 装い（設定の歯車から切り替え）

| 装い | 雰囲気 |
|---|---|
| 海辺（既定） | 淡い帯の空と海、幾何学的な風景12種（かもめ・小舟・鹿・灯台・鯨・山と月・鷺・松の島・帆船・海亀・岬の家・渡り鳥）、日付と英語の曜日・時刻。空の色は朝・昼・夕・夜で変わります。マーカーは使いません |
| 古書 | 生成りの紙、明朝、青い銅版画風の図版13種、辛子色のマーカー、アーチ |
| 星夜 | 深い紺の空に星と月。月はその日の本当の月齢で描かれ、星の並びは日ごとに変わります。夜に読むための暗い装い |
| 墨 | 白い和紙に墨色の明朝。日本語の一言は縦書きで、強調は朱の傍点。朱の落款がひとつ |
| 森 | 海辺の姉妹版。深緑と苔色、木々と獣の風景7種（鹿・狐・梟・山小屋・湖・松・小鳥）。空の色は時間帯で変わります |
| モダン | 白地に黒、飾りなし。大きな日付と太い活字だけで見せます |

フォントは Zen Kaku Gothic New（海辺・森・モダン）、Shippori Mincho + Cormorant Garamond（古書・星夜）、端末の明朝（墨。縦書きの句読点のため Hiragino Mincho など端末のフォントを使います）、Josefin Sans（小さな見出し）。
図版はすべて SVG で描いているので、外部の画像には依存しません。
`index.html?hour=21` のように付けると、その時刻の空の色で確認できます。
`index.html?now=2026-09-15T06:59` のように付けると、その日時から時計を進めた状態で表示でき、7時の切り替わりを確かめられます。
